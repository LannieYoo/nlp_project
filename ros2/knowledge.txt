[eisenstein_nlp | 18.3.1 Neural attention]
Neural attention is a mechanism that allows a model to focus on relevant parts of the input when making predictions. It computes attention weights using a scoring function, typically a two-layer feedforward network, and applies softmax activation to produce a probability distribution over input positions. This allows the model to selectively attend to important information rather than treating all inputs equally.

[murphy_pml1 | 9.4 Generative vs discriminative classifiers]
A generative classifier models the joint distribution p(x, y) = p(y)p(x|y), which can generate examples from each class. A discriminative classifier models the conditional p(y|x) directly, which can only discriminate between classes. Generative classifiers can handle missing data and detect outliers, while discriminative classifiers often achieve higher accuracy on classification tasks because they focus directly on the decision boundary.

[jurafsky_slp3 | 4.6.1 The Gradient for Logistic Regression]
The gradient of the cross-entropy loss for logistic regression is: dL/dw_j = (y_hat - y) * x_j, where y_hat = sigmoid(w dot x + b) is the predicted probability, y is the true label, and x_j is the j-th feature. This simple form means the gradient is proportional to the difference between prediction and truth, multiplied by the input feature.

[eisenstein_nlp | 6.1 N-gram language models]
An N-gram language model predicts the next word by conditioning on only the previous n-1 words, rather than the entire history. For example, a bigram (2-gram) model estimates P(w_i | w_{i-1}), and a trigram estimates P(w_i | w_{i-2}, w_{i-1}). This simplifying assumption makes the model tractable, as it reduces the number of possible contexts from V^(M-1) to V^(n-1).

[jurafsky_slp3 | 5.5.2 Learning skip-gram embeddings]
Skip-gram is a word embedding method in Word2Vec that predicts surrounding context words given a target word. It trains by maximizing the probability of context words and minimizing the probability of randomly sampled negative words. The resulting word vectors capture semantic relationships, so that similar words have similar vector representations.

[jurafsky_slp3 | 13.2 RNNs as Language Models]
Recurrent Neural Networks (RNNs) can serve as language models by processing a sequence one word at a time, maintaining a hidden state that summarizes the history. At each time step, the RNN takes the current word and the previous hidden state to predict the next word. Unlike N-gram models, RNNs can theoretically capture long-range dependencies across the entire sequence.

[szeliski_cv | 2.1.2 3D transformations]
A 3D rigid body transformation, also known as Euclidean transformation or SE(3), combines rotation and translation: x' = Rx + t, where R is a 3x3 rotation matrix and t is a translation vector. It preserves distances and angles between points. This transformation has 6 degrees of freedom: 3 for rotation and 3 for translation.

[kelleher_ml_fundamentals | 8.4.2 Weight Initialization and Unstable Gradients]
Proper weight initialization is crucial for training deep neural networks. If weights are too large, gradients explode during backpropagation; if too small, gradients vanish. Xavier initialization sets weights from a distribution with variance 2/(n_in + n_out), while He initialization uses variance 2/n_in, which works better with ReLU activations.

[kelleher_ml_fundamentals | 8.2.3 Neural Networks as Matrix Operations]
The depth of a neural network equals the number of layers that have a weight matrix associated with them. The input layer is not counted in the depth. A network with 2 hidden layers and 1 output layer has depth 3. Representing neural networks as matrix operations enables efficient computation using GPU hardware.

[murphy_pml1 | 5.1.2.2 Cost-sensitive classification]
In cost-sensitive classification, different types of errors have different costs. If a false negative costs c times more than a false positive, the optimal decision rule is: predict positive if p(y=1|x) > 1/(1+c). For example, if c=2 (false negatives twice as costly), use a threshold of 1/3 instead of 1/2.

[jurafsky_slp3 | 6.5 TF-IDF term weighting]
TF-IDF (Term Frequency-Inverse Document Frequency) measures how important a word is to a document in a collection. TF counts how often a word appears in a document, while IDF measures how rare the word is across all documents: IDF = log(N/df_t), where N is total documents and df_t is the number of documents containing the term. Words that are frequent in one document but rare overall get the highest TF-IDF scores.

[kelleher_ml_fundamentals | 8.3.1 Backpropagation]
Backpropagation is the algorithm used to compute gradients of the loss function with respect to each weight in the network. It works by applying the chain rule of calculus, propagating error signals backward from the output layer to the input layer. Each weight is then updated using gradient descent: w_new = w_old - learning_rate * gradient.

[eisenstein_nlp | 18.4 The Transformer]
The Transformer architecture replaces recurrence with self-attention, allowing parallel processing of all positions in a sequence. It consists of an encoder and decoder, each with multiple layers of multi-head self-attention and feedforward networks. The key innovation is that self-attention computes relationships between all pairs of positions simultaneously, making it much faster to train than RNNs on long sequences.

[jurafsky_slp3 | 5.2 Words and Vectors]
Word2Vec is a family of algorithms for learning word embeddings from large corpora. It includes two architectures: CBOW (Continuous Bag of Words) which predicts a target word from context words, and Skip-gram which predicts context words from a target word. Word2Vec embeddings capture semantic relationships such as king - man + woman ≈ queen.

[jurafsky_slp3 | 17.1 Named Entity Recognition]
Named Entity Recognition (NER) is the task of identifying and classifying named entities in text into predefined categories such as Person, Organization, Location, Date, and others. Modern NER systems use sequence labeling with BIO tagging: B-PER marks the beginning of a person name, I-PER marks inside tokens, and O marks tokens outside any entity.

[jurafsky_slp3 | 10.5 Beam Search]
Beam search is a decoding algorithm used in sequence generation that maintains the top-k most probable partial sequences at each step, where k is the beam width. Unlike greedy search which only keeps the single best candidate, beam search explores multiple hypotheses simultaneously. This often produces better output quality at the cost of increased computation.

[kelleher_ml_fundamentals | 8.4.4 Dropout Regularization]
Dropout is a regularization technique that randomly sets a fraction of neurons to zero during each training step, with a typical dropout rate of 0.2 to 0.5. This prevents neurons from co-adapting and forces the network to learn more robust features. During inference, all neurons are active but their outputs are scaled by the keep probability.

[kelleher_ml_fundamentals | 8.4.3 Batch Normalization]
Batch normalization normalizes the inputs to each layer by subtracting the batch mean and dividing by the batch standard deviation. This reduces internal covariate shift, allowing higher learning rates and faster convergence. It also acts as a mild regularizer, reducing the need for dropout in some cases.

[murphy_pml1 | 19.1 Transfer Learning]
Transfer learning is the technique of reusing a model trained on one task (source task) as the starting point for a model on a different task (target task). A common approach is to take a pre-trained neural network, freeze the early layers (which learn general features), and fine-tune the later layers on the new task. This is especially useful when the target task has limited training data.

[eisenstein_nlp | 9.3.2 BLEU score]
BLEU (Bilingual Evaluation Understudy) is an automatic metric for evaluating machine translation quality. It measures the precision of n-gram matches between the machine output and reference translations, with n typically ranging from 1 to 4. BLEU also includes a brevity penalty to discourage translations that are too short. Scores range from 0 to 1, with higher scores indicating better translation quality.
