# 브라우저 검증 규칙

## 핵심 원칙
**브라우저 UI 검증은 사용자가 직접 수행한다.** 에이전트는 browser_subagent를 사용한 UI 검증을 시도하지 않는다.

## 세부 규칙

1. **브라우저 자동화 테스트 금지**: 프론트엔드 변경 후 browser_subagent를 통한 스크린샷 캡처, 클릭 테스트, 검색 실행 등을 하지 않는다.

2. **대신 할 것**:
   - API 레벨 테스트: `requests` 또는 `curl`로 백엔드 API를 직접 호출하여 응답 확인
   - 코드 레벨 검증: 파일 내용 확인, 빌드 에러 확인, lint 확인
   - 서버 로그 확인: uvicorn 또는 vite의 출력 로그를 통해 에러 확인

3. **프론트엔드 변경 완료 시**: 
   - "변경 완료. 브라우저에서 확인해주세요" 등의 메시지로 사용자에게 직접 확인을 요청한다.
   - 어떤 부분을 확인해야 하는지 구체적으로 안내한다.

4. **browser_subagent 사용 가능한 경우**:
   - 사용자가 명시적으로 "브라우저로 확인해줘", "스크린샷 찍어봐" 등을 요청한 경우에만 사용한다.
